# PaperTrail

PaperTrail is a lightweight case and follow-up tracking app designed to help caregivers and advocates manage complex administrative workflows such as Medicaid applications, banking documentation, legal paperwork, and healthcare coordination.

The project is also a learning sandbox for exploring modern full-stack patterns with:

- Next.js App Router
- TypeScript
- pnpm
- GraphQL
- AI-assisted workflows

## Features (Planned)

- Create and manage issues/cases
- Track statuses and notes
- Save progress locally
- GraphQL API
- AI-generated summaries
- Suggested next steps
- AI-generated follow-up emails/messages

## Example Use Cases

- Medicaid application tracking
- Banking documentation follow-ups
- Power of attorney establishment
- Healthcare proxy coordination
- Caregiver administrative management

## Tech Stack

- Next.js
- React
- TypeScript
- pnpm
- GraphQL

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev
```

Open:

```txt
http://localhost:3000
```
